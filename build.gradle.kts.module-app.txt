Edit app/build.gradle.kts  (the one labelled "Module :app") -- NOT the Project one.

1) In the plugins { } block at the top, add the kapt plugin (needed by Data Binding):

plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    id("kotlin-kapt")          // <-- add this line
}

2) Inside android { }, add buildFeatures (if one already exists, just add the two lines inside it):

android {
    namespace = "com.example.tenantmanagementsystemgroupa"
    compileSdk = ...           // leave yours as is

    buildFeatures {
        viewBinding = true
        dataBinding = true
    }
    ...
}

3) Click "Sync Now". A warning about kapt / Kotlin 2.0 is fine -- it is not an error.
